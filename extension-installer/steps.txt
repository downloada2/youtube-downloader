Расширение скопировано. Осталось включить его в Chrome (это нужно сделать один раз):

1. Нажмите «Готово» с отмеченными галочками: откроются страница chrome://extensions и папка с расширением.
2. На странице расширений включите переключатель «Режим разработчика» (справа вверху).
3. Нажмите «Загрузить распакованное расширение» и выберите открывшуюся папку
   (C:\Users\<ваше имя>\AppData\Local\YouTube Downloader Extension).
4. Закрепите значок расширения в панели Chrome (иконка пазла) — по желанию.

Кнопки «MP3 / MP4» появятся на страницах видео YouTube. Для скачивания должна быть запущена
программа YouTube Downloader для Windows или Mac.

Chrome при каждом запуске может напоминать об отключении расширений для разработчиков — это обычное поведение
для расширений вне Chrome Web Store, закройте уведомление.
